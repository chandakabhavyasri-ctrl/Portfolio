# Bhavya Chandaka — Personal Portfolio Website

A clean, modern, and professional developer portfolio website built for **Bhavya Chandaka** (Java Developer / Software Engineer) using **Next.js 15 (App Router)**, **React**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features & Architecture

- **Clean Developer Aesthetics**: Tailored for enterprise recruiters and tech hiring managers.
- **100% Resume-Accurate Data**: Incorporates B.Tech CSE (8.1 CGPA), JSPIDERS Java Full Stack training, EduSkills internships, and enterprise Java projects.
- **Projects Highlight**:
  1. *Student Management System* (Primary Featured Project — Java, Spring Boot, MySQL, HTML, CSS)
  2. *Employee Management System* (Java Servlets, JDBC, MySQL)
  3. *Library Management System* (Java Servlets, JDBC, MySQL)
  4. *Hybrid ML Disaster Prediction Framework* (Python, Neural Networks, XGBoost)
- **Categorized Skills**: Programming, Backend, Web Technologies, Databases, Core Concepts, Tools & Soft Skills.
- **Zero-Friction Contact**: Direct email, phone click-to-call, copy-to-clipboard buttons, and a quick contact message handler.
- **Fully Responsive**: Optimized for Desktop, Laptop, Tablet, and Mobile devices with mobile hamburger navigation.
- **Production & Vercel Ready**: Clean build without errors, SEO metadata, and Open Graph configurations.

---

## 🚀 Getting Started Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub account.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel will automatically detect Next.js and deploy with zero extra configuration.
